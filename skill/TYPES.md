# 静力学题型清单（解题时先对号入座）

来源：本地两套教材（PreTeXt《Engineering Statics》101 个例题、`cfd-resources` 29 篇笔记 145 道带答案习题）
+ 哈工大版《理论力学》静力学章节划分。每类给「识别特征 / 标准步骤 / 最易错」，有模板的标出函数名。

## 一、受力分析类

**1. 约束反力与受力图** —— 模板：`templates.beam_simple` 等各型骨架
- 识别：题面「画受力图」「不计自重」，图里有铰、辊轴、固定端、柔索、二力杆。
- 步骤：先认二力构件（两端铰、中间无载、两端力共线）；按约束表解除（固定铰 2 分力、辊轴 1 法向、固定端 2 分力 + 1 力偶、柔索沿索背离物体）；只画外力不画内力。
- 易错：把二力杆画成一般铰（多一个分力），或让柔索受压。

**2. 平面汇交力系求未知力** —— 模板：`templates.two_rope_knot`
- 识别：三力汇交、销钉/小环、求两绳张力与支杆压力。
- 步骤：取汇交点；建轴让一个未知力沿轴；ΣFx=ΣFy=0 解两未知；符号判实际方向。
- 易错：角度基准线读错（与水平还是与杆），sin/cos 互换。

**3. 平面力偶系**
- 识别：轮/杆上只标 M，或两个等值反向平行力。
- 步骤：取该刚体；ΣM=0；力偶只能由力偶平衡 → 两处反力必组成力偶；由 F=M/d 反求。
- 易错：想用一对力偶去平衡单个力。

**4. 力系向一点简化（主矢主矩）**
- 识别：「向 O 点简化」「判断简化结果」。
- 步骤：定简化中心；主矢 F_R′=ΣF（与 O 无关）；主矩 M_O=ΣM_O(F)（与 O 有关）；判型（合力 / 合力平移 d=M_O/F_R′ / 力偶 / 平衡）。
- 易错：把主矢当合力——主矢作用线过 O，合力要平移。

## 二、单刚体平衡

**5. 平面任意力系求支座反力** —— 模板：`beam_simple`、`beam_cantilever`
- 识别：梁/板一端固定铰一端辊轴，受集中力、分布载荷、力偶。
- 步骤：取整体 → 优先对「两个未知力的交点」取矩，一次解出第三个 → ΣFx、ΣFy 补其余 → 对另一点再取矩校核。
- 易错：分布载荷忘了等效 ql、作用线取形心；取矩漏乘垂直分量的力臂。

**6. 平面平行力系**（塔吊、起重机、双支座梁、前后轮）
- 步骤：只用 ΣFy=0 与 ΣM_A=0 两个独立方程；对一支座取矩直接得另一端；ΣM_B=0 校核。
- 易错：照搬三个方程（第三个线性相关）；倾覆判据对错点取矩（应对可能翻转的支点取矩）。

**7. 物体系平衡 · 三铰刚架（三铰拱）**
- 识别：两刚体用中间铰 C 相连，A、B 固定铰。
- 步骤：整体 ΣM_A=0、ΣM_B=0 得两竖向反力 → 拆半，对中间铰取矩得水平反力 → 整体 ΣFx=0 得另一端 → 需要时取单杆求 C 处内力。
- 易错：只用整体三方程就收工（4 个反力，必须拆开补方程）。

**8. 套筒 / 滑块机构** —— 模板：`slider_rod`
- 识别：杆穿过套筒、标「套筒可沿杆滑动」「滑块」。
- 步骤：套筒对杆的反力 = **垂直杆方向的一个 N**（有摩擦再加沿杆 fN）；取带套筒构件为对象；对铰点取矩减少未知；解出 N 后检查 N>0。
- 易错：把套筒反力当铰链两正交分力。

**9. 静定与静不定判断**
- 步骤：数未知反力 r 与独立方程数（平面 3n、空间 6n）；r=3n 静定，r>3n 静不定，r<3n 机构；或算 W=3n−r。
- 易错：把二力杆算成 2 个未知；忘拆内部铰会多出方程。

## 三、桁架与框架

**10. 桁架节点法** —— 模板：`truss_triangle`
- 步骤：先整体求反力 → 从只有两个未知杆的节点开始 → 逐节点 ΣFx=ΣFy=0（杆力先设拉力，背离节点）→ 负值即压杆 → 用未用过的节点校核。
- 易错：拉/压方向约定不统一，整体反号；忘先求反力。

**11. 桁架截面法**
- 识别：只问少数几根杆、桁架较高节点太多。
- 步骤：整体求反力 → 作截面切断目标杆（一般 ≤3 根未知）→ 取一侧 → 对另两杆交点取矩求第三杆（两杆平行时用 ΣF=0）→ 另一侧校核。
- 易错：截面切出 4 根以上未知。

**12. 桁架零杆判别**
- 步骤：两杆节点无载荷无支座 → 两杆皆零；三杆节点其中两杆共线 → 第三杆为零；对称结构对称载荷杆力对称；删零杆后简化再算。
- 易错：把零杆当可拆除（它仍是几何组成必需）；三杆节点两杆不共线也误判为零。

**13. 框架 / 机械：二力杆 vs 多力杆**（夹钳、梁-撑杆）
- 步骤：先判每根杆是否二力杆；销钉反力不传递到另一构件，单独取销钉才能转移。
- 易错：误把三力构件当二力杆。

## 四、空间力系

**14. 空间汇交力系**
- 步骤：取汇交点；每个力写成 F(cosα i+cosβ j+cosγ k)；ΣFx=ΣFy=ΣFz=0 解三未知。
- 易错：图上给的是「与坐标面的夹角」，却直接当方向余弦用（需先投影）。

**15. 空间任意力系**（传动轴、斜齿轮、空间曲杆）
- 步骤：列六式；对某轴取矩时选让尽量多未知过轴或平行于轴的轴；先解能单独解出的方程。
- 易错：把力对轴之矩算成对点之矩（应为该力在垂直轴平面内投影 × 到轴距离）；漏轴向力。

## 五、重心、内力、摩擦

**16. 重心与形心**
- 步骤：分割成矩形/三角形/半圆等标准块 → 取对称轴为坐标轴（x̄=0）→ x̄=ΣA_i x_i/ΣA_i（细杆用长度、立体用体积）→ 挖孔按负面积 → 校核重心在对称轴上且在图内。
- 易错：权重用错；挖孔漏负号。

**17. 摩擦临界 · 单物体（含梯子靠墙）** —— 模板：`ladder_wall`、`block_incline`
- 步骤：临界时用 **等式** F=f_sN（不是不等式，临界多一个方程）；对不需要的法向力作用点取矩以避开它。
- 易错：临界仍写 F≤f_sN（少一个方程）；把两处接触都取到极限（通常只有一处先滑）。

**18. 摩擦平衡范围 / 卡滞（滑动 vs 翻倒 vs 卡死）** —— 模板：`box_between_rails`
- 步骤：按一般平衡列方程、保留 F≤f_sN → 滑动边界 F=f_sN → 倾覆边界：法向力移到支承面边缘 → 比较取小者 → 写区间。
- 易错：只算滑动不算倾覆（高窄物体常先翻）；把法向力作用点固定在中点。

**19. 摩擦角与自锁**
- 步骤：φ_f=arctan f_s；平衡条件写成全反力与法线夹角 θ≤φ_f；自锁判据：**驱动力作用线落在摩擦锥内**；斜面自锁 α≤φ_f。
- 易错：把「自锁」理解成「摩擦力够大」——判据与力的大小无关。

**20. 皮带摩擦（欧拉公式）**
- 步骤：T₁/T₂ ≤ e^{fβ}（β 用**弧度**）；临界取等号；对带轮取矩 M=(T₁−T₂)r。
- 易错：包角没换弧度或包角算错（两轮传动常见 π 与 2π−α）。

**21. 滚动摩阻**
- 步骤：临界滚动时 N 前移到接触面前缘，M_f=δN；对轮心或接触点取矩求 P；与滑动临界 P=f_sN 比较，取小者判先滚还是先滑。
- 易错：混用滚阻系数 δ（长度）与摩擦系数 f（无量纲）。

## 六、分析静力学与内力图

**22. 虚位移原理求平衡 / 求反力**
- 步骤：理想约束 → 给 δθ → 各点 δr 用 δθ 表示 → δW=ΣF·δr=0 → 解平衡位置或未知力。求反力时：解除该约束代以反力，只让该点沿反力方向动。
- 易错：把摩擦当理想约束漏掉其虚功；解除约束后仍按原机构算其他点位移。

**23. 静定梁剪力图与弯矩图**
- 步骤：求反力 → 以集中力、力偶、分布载荷起止点**分段** → 逐段取截面一侧：F_S=Σ一侧向上力，M=Σ一侧力对该截面之矩（下凸为正）→ 分布载荷段用 q 积分成抛物线 → 校核 q=−dF_S/dx、F_S=dM/dx、铰与自由端 M=0。
- 易错：弯矩正负约定与集中力偶跳变方向搞反；分布载荷段误画成直线。
